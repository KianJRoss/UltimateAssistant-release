# Contributing to Ultimate Assistant

Thanks for helping improve Ultimate Assistant. Bug reports, ideas and pull requests are welcome.

## Issues

- **Bugs:** use the bug report form with the version (in `apps/assistant/VERSION` in the install folder), your
  operating system, what you asked or clicked, what you expected, and what happened. *Download diagnostics* in the app makes a report
  you can attach; it holds no conversations, prompts, files or credentials.
- **Ideas:** describe the problem you want solved before the solution.
- **Security problems:** never in a public issue. Follow [SECURITY.md](SECURITY.md).

## Pull requests

This repository holds the source of each published release. Development happens in a separate repository, so
an accepted pull request is merged there and arrives here with the next release, credited to you in the
release notes.

1. Open an issue first for anything larger than a small fix, so the approach can be agreed.
2. Keep the change focused and say how you checked it (which system, what you ran).
3. Mention any change to privacy, permissions, network access or cost.
4. Leave out credentials, personal paths, logs and screen captures.
